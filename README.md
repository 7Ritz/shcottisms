# Shcottisms 

Shcottisms is a short bash script I'm developing which when executed echoes a random Scottism. 

I aim to perhaps implement this into my Neofetch config for a nice looking Scottism whenever I boot up my terminal. 

If you DON'T know what a Scottism is, find out, or you're just #NotQualifiedToKnow

## Installation

Copy the contents of `shcottisms.sh` to any unused line in `~/.bashrc` to have random Scottisms on terminal startup!
